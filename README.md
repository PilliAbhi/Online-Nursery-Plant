# 🌱 Online Nursery Plant Shopping Website

An online nursery plant shopping web application developed using **Python Flask**.  
The system allows users to browse plants, add them to cart, and enables an admin to manage plant products.

---

## 📌 Project Objectives

- To provide an online platform for purchasing nursery plants
- To manage plant inventory digitally
- To implement user authentication and cart functionality
- To use SQLite database with Flask ORM

---

## 🧰 Technologies Used

- **Backend:** Python 3, Flask
- **Frontend:** HTML, CSS, Bootstrap
- **Database:** SQLite
- **ORM:** Flask-SQLAlchemy
- **Authentication:** Flask-Login
